前半部分为PIDcorr相关笔记，相关链接为pidcorr.pdf

一些分析采用了PID重采样而非PID效率修正的方法。

  • 将MC的PID响应替换为由一个参数化的PID分布所随机产生的分布

  • 当我们在MVA中使用到了PID信息时非常重要

这种方法存在一些局限：

  • ProbNN变量依赖于$P, \eta, N_{track}$以外的变量或参数

  • 一些径迹的PID变量是关联的（一条$K-like$的径迹就不会表现为$\pi-like$），而在程序包中这种关联被忽略，因此不能同时使用一条径迹的多个PID信息用于MVA

PID 重采样是如何工作的?
假定我们已知刻度样本（即data）的PID分布函数$p_{exp}(x p,\eta,N_{track})$，其中$x$为PID变量。

计算$x$的归一化累积分布

\[\xi=\frac{\int_{x_{min}}^{x_{corr}}p_{exp}(x|p,\eta,N_{track})\mathrm{d}x}{\int_{x_{min}}^{x_{max}}p_{exp}(x|p,\eta,N_{track})\mathrm{d}x}\]

第二节 中微子实验的技术

  • 实验对探测器主要性能的要求

    • 探测效率：入射粒子数目与输出粒子的电信号的比值
    • 响应函数：测量的物理量与输出电信号的关系 （刻度(calibration)：获得响应函数的过程）
    • 分辨率：物理量的测量精度
    • 动态范围：可测物理量的范围，特别是阈值
    • 辨别本底的能力
    • 稳定性和可靠性
    • 其他：成本、复杂程度……

  • 中性强子探测中的转换

    从热中子到几个$\mathrm{MeV}$能量的中子，可以使用如下的核反应

    $n+6Li\to\alpha+3H$

    $n+10B\to\alpha+7Li$

    $n+3He\to P+3H$

  • $\gamma$探测中的转换过程
    • 光电效应
    • 康普顿散射
    • 电子对产生

    • CC带电流反应

      $\nu+p\to n+l$

      $\nu_\mu+N\to\mu+X(\mathrm{shower})$

    • NC中性流反应

      $\nu_\mu+N\to\nu_\mu+X(\mathrm{shower})$

    • 与核子的非弹性散射

      $\nu_e+(A,Z)\to e^++(A,Z-1)$

    • 中微子-电子散射

      $\nu_e+e\to\nu_e+e$

    • 中微子-原子核散射

      $\nu_e+(A,Z)\to\nu_e+(A,Z)$

黄金反应-反beta衰变反应

\[\bar{\nu}_e+p\to e^++n\]

不同能量中微子采用不同探测技术

  • $0.1-1\mathrm{keV}$：超低温量热探测技术
  • $\mathrm{keV}-\mathrm{MeV}$：固体闪烁体或半导体探测器——实时+能量测量方法
  • $\mathrm{MeV}-\mathrm{GeV}$：水切伦科夫探测器，液闪
  • $\mathrm{GeV}-\mathrm{TeV}$：高能物理探测器

二、JUNO实验介绍

中微子振荡——超出标准模型的物理现象

  • 按照弱相互作用本征态：$\nu_e,\nu_\mu,\nu_\tau$

  • 质量本征态分类：$\nu_1,\nu_2,\nu_3$

  • 一种味道本征态由三种质量本征态混合而成

  • 两种可能得质量顺序：

    • $\nu_1<\nu_2<\nu_3$

    • $\nu_3<\nu_1<\nu_2$

  • JUNO实验

    • 物理要求实验点只能在距离反应堆$50-60\mathrm{km}$之间且到所有反应堆距离相等

    • 实验点由山（越高越好）

    • 实验选址：江门开平市金鸡镇打石山

    • 整体布局

      • 山高$241\mathrm{m}$，探测器中心海拔$-453\mathrm{m}$

    • 为什么在山下$700\mathrm{m}$？

      • 宇宙射线产生大量类中微子信号（本底）

      • $700\mathrm{m}$岩石可以将宇宙线流强压低数万倍

    • 探测器设计需求：中微子质量顺序

      • 体积大，快速积累事例：两万吨液闪，比此前国际最大液闪探测器大$20$倍

      • 能量分辨率高，区分精细振荡结构：$3\%@1\mathrm{MeV}$，比此前国际最好水平高$1$倍

      • 放射性本底极低：$\mathrm{U}^{238}$、$\mathrm{Th}^{232}$达到$10^{-15}~10^{-17}$，与$500$吨探测器水平相当

      • JUNO运行$6.7$年中微子质量顺序灵敏度达到$3\sigma$!

    • 探测器部件

      • 天然放射性本底

        不稳定原子核自发放出$\alpha,\beta,\gamma$射线，与中微子信号特征相似

        • 自然界天然存在的铀，钍，钾

        • 放射性核素衰变产生的氡、镭

        • 核试验产生的氪

什么是Linux?

  • Linux: 一种操作系统内核

    • 基于Linux内核，捆绑具体应用 $\rightarrow$ 不同“发行版”

  • 命令行与shell

    • Linux的任务可以分为两部分：

      • 承担操作系统与计算机之间的互动：内核(kernel)

      • 承担操作系统与用户之间的互动工作

        • 命令行：用户与操作系统的直接交互

          由终端(terminal)输入，不同于Win

        • shell: 命令解释器

          • 广泛应用的几大类shell（即指令集）: sh, csh, tcsh, bash, zsh, ……

  • 文件与目录

    • Linux由自己的文件系统格式

    • 根目录：/

  • 文件的所有者属性与访问权限

    ls -l 可以查看文件所有者属性与访问权限，通常格式如下：

    drwxr-xr-x 27 liuyl lhcb 4096 Jul  8 19:55 liuyl # 4096代表了文件的大小，可以通过ls -lh查看人类可读的模式

    • r,w,x代表了文件的访问属性

      • r: readable

      • w: writable

      • x: executable

    • 三层权限对应什么？

      属主(user)、属组(group)、其他人(other)

    • 如何改变这些属性？

      chmod u+w test.py # 给user writable的权限
chmod 755 test.py

  • 环境变量

    我们尝试了很多命令，但是操作系统怎么知道我们想用的命令在哪里？如果系统在不同目录存在多个相同名称怎么办？

    • 环境变量：当前进程的配置字典

      shell中有很多环境变量，查看所有环境变量printenv或env

    • PATH: 一个重要的环境变量

      该环境变量的值是一个路径列表，路径之间用“:”分隔。当我们让系统执行某个命令时，系统会按照这个路径列表搜索，直到找到为止。如果某个命令所在目录不在PATH中，则执行该命令的时候需要加上路径，例如/sbin/ifconfig

      用which命令可以查看某个命令位于何处或是否存在。该命令从$PATH中的第一个目录开始搜索，例如which sed

    • 使用环境变量

      设置环境变量：export myVar=value

      查看环境变量：echo $PATH

      取消环境变量：unset myVar

      有时可能需要追加些东西到某个变量中，例如PATH：export PATH=:$PATH

      “command not found”仅表示无法在$PATH中找到需要的命令，不代表操作系统中不存在该命令

    • 脚本

      Linux命令的基本原则是一个命令实验一个简单的任务或功能，但是你的要求可能很高很复杂，有时你可能需要重复运行很多类似的程序代码 $\rightarrow$ 将多个shell命令组合到一起

      • shell脚本

        脚本可以实现复杂功能或简化很多重复工作，有助于你更高效高产腾出时间做更有用的事情

      #!/bin/bash/

echo "Hello World!"
date
echo $PWD

      1. 第一行以 “#!”开头，后面跟随所用shell的绝对路径

      2. 其他以 “#” 开头的行为注释行 (注意“其他”二字)

      3. 可以把任何需要的命令行命令放到脚本中

      4. 执行脚本test.sh

      • source test.sh

      • ./test.sh（需保证test.sh具有x属性）

  • Snakemake工作流管理
    • 为什么需要工作流管理？
      • 数据分析通常包含多个步骤：训练 → 检查 → 应用 → 拟合 → 汇总
      • 手动逐步执行繁琐易错，难以复现
      • 团队协作需要统一、可读的流程管理
    • Snakemake优势
      • Python-based，可读性高
      • 自动处理依赖关系，只运行需要更新的步骤
      • 支持多核并行（–cores n）
      • 有助于形成健康的代码管理结构
    • 教程：http://hpc.ncpgr.cn/app/093-snakemake/

  • 设置.bashrc

    • ~/.bashrc是Bash在启动交互式非登录Shell时执行的用户级配置文件

    • 在登录Shell（如ssh）场景下，标准做法是在.bash_profile中显式检查并加载.bashrc

    • 个性化设置
      • 命令行提示符: e.g. PS1=’[\e[;;7m][\u@\h][\e[;;0m] \w $[\033[00m] ’
      • 添加环境变量：export PATH=$PATH:/path/to/your/executable
      • 添加别名：alias ll=“ls -lh”
      • 执行预设命令：lb-run DaVinci
      • 定义函数 etc.
